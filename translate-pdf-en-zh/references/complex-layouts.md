# 复杂版面

## 扫描件、隐藏 OCR 层和文字转曲

可提取文本不等于可替换：整页扫描图上常有不可见 OCR 文本，删除隐藏文字并不会删除图中英文。检查渲染、图片覆盖区域及文字渲染模式。

1. 左页保持原 PDF，只有右页做 OCR 和图像处理。
2. 约 300 DPI 或更高分辨率渲染，用可用的本地 OCR 提取词/行框与置信度；对照原图校正列序、表格、数字和语句。关键文字无法辨认时说明，不猜测。
3. 像素坐标按实际比例转为 pt，记录裁剪、旋转、去倾斜造成的全部变换。
4. 仅清理英文笔画所在局部白底区域，保留线框、插图和背景。白矩形跨越表格线/曲线时应细分遮罩或恢复线条，不用大白框遮盖一切。
5. 把中文作为可搜索的嵌入字体文字层加回右页；清除或更新隐藏的 OCR 英文，避免复制出来仍是英文。
6. 复杂背景文字必要时局部重建。不能无损处理时说明局部限制，不把整页重排成新文章。

`apply` 拒绝与图片重叠的文字，不适用于上述路径；定制脚本完成右页后仍可用 `pair`。

## 表格、多栏和公式

- 按单元格排版，保留网格、合并单元格及行列关系；不把整表作为一个段落。
- 多栏按几何位置识别列序，不简单按全页 y 坐标排序。
- 图例/标注留在对应图中，保留箭头、曲线、颜色、比例尺与数值。
- 字符框可能重叠，redaction 按字符框相交移除；执行前检查相邻保留文字，避免误删。
- 数学公式、上下标、分式和编号优先原样保留，只翻译旁边自然语言。行内混排拆分并精确定位，不整体中文覆盖公式。

## 字体、特殊页面

混合字体/颜色/大小的块按语义分区域，保留强调与上下标。不能逐词机械翻译来维持英文词宽。字体需嵌入并覆盖全部字符，缺字时选择回退字体分段渲染。宋体 TTC 的首字体通常可用，仍需渲染确认。中文无直接斜体对应时采用克制的强调方式。

规范化 CropBox、MediaBox、旋转至可见页面坐标。只在副本中规范化及烘焙批注，`pair` 的左侧渲染比对用于检测偏差。动态表单、多媒体、签名等交互语义不保证在静态拼页中保留。密码保护文件需可用密码，不能绕过权限。

## API 依据

[PyMuPDF Page 官方文档](https://pymupdf.readthedocs.io/en/latest/page.html)：查 `apply_redactions`、`remove_rotation`、`insert_textbox` 和 `show_pdf_page`。明确设置图片/图形保留选项，不依赖 redaction 默认行为；拼页不会自动复制交互对象，应先在副本保留其可见外观。
